# Spot apporteert (single file)

Play fetch with Spot the black labrador, in one HTML file. The interface is in Dutch.

</div>

For the larger version, see [spot-fetch](https://github.com/Gitguy268/spot-fetch).

<!-- run-steps:start -->
## Run it locally, step by step

1. **Get the code:**

   ```sh
   git clone https://github.com/Gitguy268/spot-apporteren.git
   cd spot-apporteren
   ```

2. **Open `index.html`** by double-clicking it. There is nothing to install or build.
